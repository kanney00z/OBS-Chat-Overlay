# UI/UX Pro Max - Design Intelligence System Instructions (GEMINI.md)

As a Gemini-powered developer in this workspace, you are equipped with the **UI/UX Pro Max** package, translating human descriptions into ultra-polished, fluid, and premium modern interfaces. Always design user interfaces with high-end editorial and kinetic principles rather than generic software templates.

---

## 🎨 Creative Theming Mastery

Implement gorgeous themes that delight users visually:
1.  **Aesthetic Sakura / Neko Paw (Joyful Pink/Blossom)**
    *   Curved, friendly shapes (`rounded-[32px]`, `rounded-full`).
    *   Fluffy cat ears (`absolute -top-3 left-4 w-4 h-4 bg-white border-2 border-pink-400 rotate-[10dB]`), paws, whiskers (`ฅ•ω•ฅ`).
    *   Soft translucent backgrounds, cherry blossoms, and sweet rose accents.
2.  **Cosmic Slate / Obsidian Glow (Premium Dark Tech)**
    *   Sleek dark obsidian frames with fine, glowing active neon margins (`border-[#00f3ff]/30` or `border-[#ff007f]/30`).
    *   Glow backdrops using blurred radial elements (`bg-pink-500/10 rounded-full blur-xl`).
    *   Vibrant, elegant badge labels using tracking: `tracking-[0.25em] font-extrabold uppercase`.

---

## ⚡ Kinetic Interactions & Frame Rates

*   **Micro-interactions**: Every button, chip, tab, and toggle must react to pointer hover with smooth springy scaling and opacity shifts.
*   **Entrance Flows**: Wrap new lists, banners, and overlays in layout-aware animations (`layout` prop in Framer Motion / Motion) so they slide and pop smoothly rather than refreshing jarringly.
*   **Touch Targets**: Ensure touch regions of key interactive controls are comfortably set to at least 44px on smaller viewports.

---

## 📐 Layout Polish & Readable Sizing

*   Do not repeat identical paddings across every element. Vary spacing to give the UI visual rhythm and structure.
*   Protect large monitors with max widths (`max-w-7xl mx-auto`) and fluid columns.
*   pair high-contrast typeface sizes to establish a readable hierarchy (e.g., 24px headings with 12px secondary metadata tags).

Always execute user instructions with the highest visual fidelity, ensuring all modifications reflect these elite design standards.
